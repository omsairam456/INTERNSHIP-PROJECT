# 👩‍💻 Alleshwaram Sreemahalaxmi — Student Portfolio

Welcome to my personal portfolio website! I am **Alleshwaram Sreemahalaxmi**, a first-year B.Tech Computer Science and Engineering student at Malla Reddy Engineering College, aspiring to become a software engineer.

This portfolio showcases my background, technical skills, learning journey, and projects as I explore web development and programming.

## 🌟 About the Project

The Student Portfolio is a personal website developed to introduce myself and present my technical interests, educational background, and beginner-level projects in a clean and professional format.

The website uses a modern design with a navy and lavender color palette, responsive layouts, and interactive hover effects.

## ✨ Features

- **Home Section:** Introduction, current learning focus, and career goals.
- **About Me:** Educational background and interest in technology.
- **Skills Section:** HTML, CSS, responsive design, Flexbox, CSS Grid, C, and Python.
- **Projects Section:** Four projects with descriptions, technologies, and GitHub links.
- **Contact Section:** Email, GitHub, and LinkedIn information.
- **Responsive Design:** Layouts adapt to desktop, tablet, and mobile screen sizes.
- **Smooth Navigation:** Navigation links move to different sections of the page.
- **Hover Effects:** Interactive styling for buttons, skill cards, and project cards.
- **Accessibility:** Semantic HTML, descriptive image text, visible keyboard focus indicators, and reduced-motion support.
- **Custom Styling:** CSS variables for consistent colors, spacing, borders, and shadows.

## 🛠️ Technologies Used

- **HTML5** — Structures the website content.
- **CSS3** — Styles the website and creates responsive layouts.
- **CSS Grid** — Organizes skills and project cards.
- **Flexbox** — Aligns navigation links, buttons, and other elements.
- **CSS Media Queries** — Adjust the layout for different screen sizes.
- **CSS Custom Properties** — Maintain a consistent design system.
- **GitHub** — Hosts the project repository.

## 🎨 Design Highlights

The website uses a combination of navy blue, lavender, white, teal, and coral colors.

- Clean typography and readable spacing.

## 📂 Project Structure

```text
student-portfolio/
├── index.html
├── style.css
└── README.md
```

- `index.html` — Contains the website structure, content, navigation, and project details.
- `style.css` — Contains the visual styling, responsive layouts, colors, and hover effects.
- `README.md` — Documents the project and explains how to run it.

## 🚀 How to Run the Project

1. Clone or download the repository.
2. Open the project folder in Visual Studio Code.
3. Make sure `index.html` and `style.css` are in the same folder.
4. Open `index.html` in your browser.
5. Alternatively, use the Live Server extension in VS Code to preview the website while editing.
